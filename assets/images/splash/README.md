# Splash Screen Assets

Folder ini digunakan untuk menyimpan gambar splash screen KASFLO.

Nama file yang disarankan:

- `sugoi8-logo.png` — logo Sugoi 8 dengan latar transparan.
- `kasflo-splash.png` — gambar splash screen penuh jika diperlukan.
- `kasflo-icon.png` — ikon aplikasi atau favicon.

Untuk logo, gunakan PNG transparan atau SVG dengan ukuran minimal 512 × 512 px.
